# My dotfiles
Hyprland dotfiles. Spun off [JaKoolIt](https://github.com/JaKooLit/Hyprland-Dots)

This is my current dots on Debian sid.

Works on Hyprland 0.54+.

## Softwares
- OS: Debian sid
- WM: Hyprland (see my other project, [Hyprbian](https://github.com/imchocomint/hyprplus))
- Terminal: Kitty
- Top bar: Waybar
- Menu, clipboard manager, etc: rofi
- System monitor: btop
- Fetcher: fastfetch
- Notification manager: swaync
- Other softwares: cava, yazi, awww, fcitx5, nm-applet, wl-clipboard, wallust, thunar, pulseaudio, cliphist, nwg-bar ... (tba)
